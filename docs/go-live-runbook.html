0 The platform itself Complete
0.1Done

Full storefront & admin, built and tested

Storefront, admin panel, consultations, reviews/returns, CMS, analytics, legal pages and gifting are all built. 39 automated tests pass; the whole purchase flow is proven end-to-end against a real database. All work is on the master branch, tagged v0.1 through v1.1.

1 Kick off the long poles Start today
1.1Client / External

Begin Razorpay business verification (KYC)

Sign up at razorpay.com with the business details and submit KYC — business PAN, bank account, and address proof. Once approved, Razorpay issues live API keys and the money from orders settles into that bank account. This is the single longest wait, so it goes first.

Why the client:KYC is tied to a registered business and its bank — it can't be your personal account if the business is the client's.

1.2You

Confirm the domain and account ownership

Make sure sarthakarts.com is registered (buy it if not). Decide the single account that will own production — hosting, database, email, payments. For a real handover this should be the client's business email/logins, so nothing important sits on a personal account.

2 Make it production-ready In parallel
2.1Done

Move certificate storage to the cloud

Done — the storage layer now supports cloud buckets (Cloudflare R2 or Amazon S3), chosen by a single setting. It just needs a bucket and its keys plugged in at deploy time.

2.2Done

Separate demo data from real data

Done — production setup (npm run db:seed:prod) loads only the essentials (directions, currencies, order statuses, settings, page copy, and the owner + consultant logins) with no sample products. You add the real catalogue through the admin.

2.3Done

Hosting configuration & guide

Done — pooled/direct database connections for serverless are wired, and a full step-by-step DEPLOYMENT.md covers Neon, Vercel, R2, Razorpay, Resend, and the domain.

2.4YouDeveloper

Create the production database

Create a fresh Neon database under the client's account (separate from the demo one used to build this). I then run the setup and the production seed against it, so it starts clean with real settings and your admin account.

2.5You

Put the code on GitHub & connect the host

Create a GitHub repository under the client's account, push the code there, and connect it to the host. From then on, every update deploys automatically.

2.6YouDeveloper

Set the secret keys on the host

Enter the production values in the host's settings: database link, a fresh login secret, admin email/password, the Razorpay live keys (from step 1.1), the email key (step 3.2), and the storage keys (step 2.1). I'll give you the exact list; you paste the values so the secrets stay with the client.

3 Switch on payments & email After KYC clears
3.1Client / External

Go live on Razorpay

Once KYC is approved: add the live keys to the host, register the webhook address (https://sarthakarts.com/api/webhooks/razorpay) with its secret, and switch from test to live. Then place one small real order to confirm money flows and the order appears.

Note:the payment engine is already built and proven in test mode — this only swaps the keys on.

3.2You

Turn on order & booking emails

Sign up for an email service (Resend is a good fit), verify sarthakarts.com as a sending address by adding a few DNS records, and add its key to the host. Order confirmations, certificates, and booking emails then send automatically — the code already handles them.

4 Real content Before opening
4.1You

Add the real products & photography

Through the admin: add each real murti and Vastu piece — name, description, exact price, materials and weights, direction and purpose, and real photos. The sample products don't carry over to production, so you start with a clean catalogue.

4.2You

Review the legal & store copy

In Admin → Content, read through the Terms, Privacy, and Shipping & Returns drafts and adjust them (ideally with a quick legal check). Also set your store name, announcement bar, and shipping/tax to real values in Settings.

5 Open for business Launch
5.1YouDeveloper

Point the domain & do a final check

Connect sarthakarts.com to the host and confirm the padlock (HTTPS) is on. Then walk the whole thing once on the live site: browse, buy one real item, confirm the order, certificate, and email all arrive, and that it shows up in the admin.

5.2You

Announce and take orders

Share it — social, WhatsApp, whoever's waiting. The store is open.

All developer work is done (the platform is complete and deploy-ready through v1.3, with a full DEPLOYMENT.md).
