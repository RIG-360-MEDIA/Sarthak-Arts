# Consultation hero — portrait ovals

Drop three portrait images here and they appear instantly in the rotating ovals
on `/consultation` (with no code change needed):

- `1.jpg`  → left oval
- `2.jpg`  → centre oval
- `3.jpg`  → right oval

Tips:
- Portrait orientation works best (the ovals are taller than wide, ~2:3).
- Any web format works if you name it `.jpg` — or ask the developer to change
  the extension in `src/app/(storefront)/consultation/page.tsx`.
- Until these files exist, the ovals gracefully show the metallic piece renders.
